Política de privacidad del asistente de FerreLupe

Este asistente de WhatsApp es parte de un proyecto de título de Ingeniería en Informática del Instituto Profesional Iplacex. Atiende consultas de clientes de la ferretería FerreLupe: busca productos, calcula materiales y envía cotizaciones.

Qué datos se guardan

El número de teléfono y el nombre de perfil de WhatsApp de quien escribe, el texto de los mensajes de la conversación y las cotizaciones que se generan.

Para qué se usan

Solo para responder las consultas, preparar las cotizaciones y permitir que el personal de la ferretería continúe la atención. Los datos no se venden ni se comparten con terceros para publicidad.

Servicios que intervienen

Los mensajes se reciben y se envían mediante la API oficial de WhatsApp (Meta). Para redactar las respuestas, el texto de la conversación se procesa con la API de Claude (Anthropic). Los datos se almacenan en una base de datos de Microsoft Azure.

Eliminación de datos

Puedes pedir que se borren tus datos escribiendo «borrar mis datos» en la misma conversación de WhatsApp. El personal de la ferretería eliminará la conversación y tus datos de contacto.
